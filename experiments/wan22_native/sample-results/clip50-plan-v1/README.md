# Measured full-clip plan

This CPU-only plan validated the completed core and decoder records, their input/source identities, and the fixed 50-step solver before generation. The estimate was 692.60 seconds against a 900-second limit. It loaded no foundation weights and ran no model inference.

The subsequent [complete generation](../clip50-v1/README.md) took 527.57 seconds but failed visual inspection. A timing estimate alone cannot establish image quality.
