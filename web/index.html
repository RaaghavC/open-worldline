About Worldline

Worldline is a research prototype that generates terrain and vegetation fields with an original, locally trained neural model. A separate trained model predicts changes in water, vegetation and heat.

The 3D landscape uses Three.js geometry, foliage and shaders to display those fields. The graphics are rendered, rather than generated video frames. World edits and saved history are explicit software features.

Descriptions select alpine, desert or alien using a small keyword vocabulary. This is not a general text-to-world model. The training environments are synthetic.

Genie 3 parity has not been established. Neither research novelty nor three revolutionary advances have been demonstrated. This prototype provides working code and measurable experiments toward further research.
