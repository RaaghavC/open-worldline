# Memory and action research supplement, September 7, 2026

This supplement adds five methods omitted from the initial catalogs: FloWM, Latent Spatial Memory, Olaf-World, WorldKV and ABot-World-0. These are existing methods with mechanisms relevant to our observed failures. Their inclusion would not establish that Worldline has implemented them or achieved their results.

The audit checked the initial research review, its three source catalogs and architecture evidence. These five papers were absent from those documents at the time of the check. Existing entries already cover WorldMem, DecMem, Lyra, WorldPlay, CAER, CoCo, Self Forcing, Causal Forcing, VGGT-World, Matrix and related methods. This audit used nine targeted search queries, followed by primary-source paper, repository and model-card reads. No model, dataset payload, GPU process or training job was started. Small repository metadata, licenses and READMEs are retained in [the retained source records](research-memory-action-sources/manifest.json).

All paper dates below come from arXiv submission histories. Repository snapshots were selected with GitHub's commits endpoint through September 7 in the user's America/Los_Angeles timezone. The newest selected code commit is September 4. All inspected Hugging Face release metadata also predates the cutoff. Search crawler dates were not used as release dates. Authors' performance and novelty statements remain author claims. No independent benchmark reproduction occurred.

## 1. FloWM: spatial memory that moves with the observer and dynamic objects

**Dates and primary evidence.** *Flow Equivariant World Models: Memory for Partially Observed Dynamic Environments* was submitted January 3, revised May 28, 2026, and accepted at ICML 2026. It maintains spatial latent memory whose transformations follow self-motion and inferred object motion. Its controlled evaluations include moving objects that leave the camera view and return. This is more directly relevant to invisible-state retention than a generic increase in recurrent hidden width. [Paper history](https://arxiv.org/abs/2601.01075), [author project](https://flowequivariantworldmodels.github.io/).

**Mechanism and measured scope.** A visual encoder writes into a spatial memory; separate velocity channels move retained features forward. Known navigation actions transform that memory to keep its coordinates aligned. The 3D benchmark uses discrete 90-degree turns and grid movement; blocks bounce at walls but do not collide with each other or the agent. The paper reports a 10M-parameter 3D model, 150k steps on two H100s and a 12.5% teacher-forcing ratio. These are controlled dynamics results, not open-world photorealism or a solution for arbitrary semantic actions. [Method, limits and Appendix G](https://arxiv.org/html/2601.01075v2).

**Release and license.** [Code snapshot](https://github.com/hlillemark/flowm/tree/c909c54a3d58ae240de03f5ebbec222d3e6b1264), committed July 29, contains training/inference, baselines and data-download scripts; code license is MIT. Official [Block World checkpoints](https://huggingface.co/flowm123/blockworld-models/tree/693920b5fc0331a436c1ecb7aaf9bcc26e81138a) and [MNIST checkpoints](https://huggingface.co/flowm123/mnistworld-models/tree/72affe592a5b184d51b37b87ad5358362bbcaa1e) exist. Metadata lists a 154,335,485-byte dynamic FloWM checkpoint and a 904,582-byte MNIST FloWM file. Their model cards/API have no declared weight license; do not infer MIT permission for these weights from the code license. Checkpoint bytes were not downloaded or deserialized.

**Implementable hypothesis for Worldline, not a result.** Replace global pooling into the Room GRU with a small spatial feature map, keep a separately scored memory-reset arm, and train a visual write gate. Test navigation alignment with only observed RGB and action history available. Our 7.5-degree Room yaw and interaction toggle differ from the paper's exact grid rotations, so a copied `rot90` update is not valid. An interaction write must depend on visible evidence and reachability; a fixed toggle from action ID would fail the existing out-of-reach controls. First measure retrieval of an observed door appearance after looking away; add dynamic transport only with an independently testable moving-object task. No hidden simulator pose, object state or future image may enter rollout.

## 2. Latent Spatial Memory / Mirage / LSM-World: persistent geometry directly in video latents

**Dates and primary evidence.** Submitted June 8 and revised August 27, 2026. The revision's abstract uses *Mirage*, while the project and paper figures also use *LSM-World* for the same paper. It lifts depth-associated video latent tokens into a 3D cache and projects them into requested views, avoiding the RGB render-and-VAE-reencode cycle. The authors report up to 10.57x generation speed and 55x smaller memory relative to their explicit RGB-cache baselines. These ratios are benchmark-specific, not a prediction for the Mac. [Paper history](https://arxiv.org/abs/2606.09828), [paper](https://arxiv.org/html/2606.09828v2).

**Release and license.** The MIT [code snapshot](https://github.com/microsoft/LatentSpatialMemory/tree/be530516a8b8c79ae5d5dff543b4d1640f59bd54), committed August 27, contains preprocessing, inference and `scripts/train.py`. Its example uses **Wan2.2 TI2V-5B**, VACE plus LoRA and 10,000 updates. This matches the foundation family now being profiled locally. The inference command expects separately trained `vace.safetensors` and `lora.safetensors` files. No author adaptation-weight download link was verified in the README or project during this bounded audit; base Wan weights alone do not supply trained memory. Source dependencies and data permissions remain separate from the repository's MIT license. [Pinned README](https://github.com/microsoft/LatentSpatialMemory/blob/be530516a8b8c79ae5d5dff543b4d1640f59bd54/README.md).

**Implementable hypothesis for Worldline, not a result.** A future native48-channel memory adapter could store previously observed features and retrieve their projected views. Start with a reconstruction-only cache test: encode an observation once, retrieve at the same view and measure feature error and storage. Then compare trained retrieval against a recent-window baseline on fixed return trajectories. Depth and pose must be estimated from available RGB/actions or explicitly declared extra inputs; our private renderer's depth cannot silently become inference input. The published cache emphasizes static scene content. It does not alone track whether a hidden door changed or whether a stale stored appearance should be replaced. Evaluate static revisit and mutable-object state separately, and do not treat the current untrained Wan port as this model.

## 3. Olaf-World: align latent actions with observed effects across scenes

**Dates and primary evidence.** Submitted February 10, revised May 26, accepted at ICML 2026. Its SeqΔ-REPA loss aligns a projection of averaged inferred action latents with averaged temporal differences from a frozen video encoder. This constrains action coordinates across clips, where good next-frame reconstruction alone can leave scene-specific latent conventions. The paper tests action transfer and limited-label adaptation. [Paper history](https://arxiv.org/abs/2602.10104), [equations and experiments](https://arxiv.org/html/2602.10104v2).

**Release and license.** The MIT [code snapshot](https://github.com/showlab/Olaf-World/tree/3729342d42722e8c2d3ac8db2bc5f53c09d30d08), committed April 20, includes latent-action training and world-model inference. World-model pretraining, fine-tuning, evaluation and distillation remain listed as TODO. The official [weight repository](https://huggingface.co/YuxinJ/Olaf-World/tree/9bc978f2079f51fa21ffd8a3b4640d8680c0a76b) declares Apache-2.0 and exposes LAM checkpoints plus a 15,645,917,769-byte `world_model/pretrain/model.pt`. The required SkyReels base model has a separate [Skywork license label](https://huggingface.co/Skywork/SkyReels-V2-I2V-1.3B-540P/blob/main/LICENSE), so the combined stack cannot be described as unrestricted merely from Olaf's labels. No checkpoint values or complete dependency licenses were audited.

**What this could address.** It offers a concrete training signal against learning scene appearance as an action shortcut. The reported LAM training uses eight H200s for about 4.5 days; “one minute” downstream adaptation is not the cost of learning the prior. [Training details](https://arxiv.org/html/2602.10104v2).

**Implementable hypothesis for Worldline, not a result.** On existing original trajectories, train a small action-effect projection from RGB differences and compare cross-scene action retrieval before any foundation fine-tuning. Use future frames only to construct the training target. At inference, use actual controls through a learned mapper; do not infer a control latent from the unavailable next truth frame. A direct limitation follows from the stated loss: the mean temporal difference telescopes to `(last feature - first feature)/K`, so a completed camera return can have nearly zero signal despite substantial intervening motion. Predeclare short transition windows, include null/failed interactions, report cancellation cases, and retain the sequence-order control. This is a test of an existing idea, not an established fix for the sparse door toggle.

## 4. WorldKV: retain and retrieve evicted native attention memories

**Dates and primary evidence.** Submitted May 21, 2026. World Retrieval archives evicted attention key/value chunks, indexes them by camera/action correspondence, and restores relevant chunks without encoding RGB again. World Compression keeps an anchor and prunes redundant keys by similarity. The authors compare against full-history and sliding-window attention on Matrix-Game 2.0 and LingBot-World-Fast, reporting roughly twice the throughput with comparable memory fidelity. [Paper](https://arxiv.org/abs/2605.22718), [author methods page](https://cvlab-kaist.github.io/WorldKV/).

**Release and license.** [Code snapshot](https://github.com/cvlab-kaist/WorldKV/tree/046f6d19890555fd4601e8888d7258bee12fad01), committed July 18, declares Apache-2.0. It supplies a concrete LingBot inference command, camera intrinsics and OpenCV pose arrays, and a four-GPU example. The raw README's progress list marks LingBot complete and the other two integrations incomplete. It adds no trained weights; the example downloads external LingBot base/fast checkpoints. Those checkpoints' terms and hardware requirements still apply. [Pinned README](https://github.com/cvlab-kaist/WorldKV/blob/046f6d19890555fd4601e8888d7258bee12fad01/README.md).

**Implementable hypothesis for Worldline, not a result.** For a future causal attention backbone, archive observation-derived K/V chunks and compare retrieval with full-cache and recent-window conditions under identical generation noise. Add a stale-memory challenge where a door has changed since the last stored view. Report cache bytes, retrieval latency, revisit error and stale-state errors separately. This cannot be dropped into the current bidirectional native Wan clip model, which has no persistent causal cache across chunks. It also does not repair the pooled Room GRU by itself. If retrieval requires estimated pose, report that input and its errors. Exact teacher poses would change the current RGB/actions-only contract.

## 5. ABot-World-0 / LongForcing: extend teacher supervision over actual generated history

**Dates and primary evidence.** Paper submitted July 21, 2026; the repository dates the causal-model release July 9. LongForcing trains on long student self-rollouts with an extended-horizon teacher during DMD. The comparison already gives both arms generated histories and final-stage DMD; the distinguishing factor is teacher supervision horizon. Its 60-second evaluation measures preference-related quality, saturation, blur and repetition. The quoted 720p16 result is actually 1280x704, up to 16 FPS on an RTX 5090, with 1.2-second first-frame latency and at most 19.3 GiB at optimized low-bit operating points. These are author measurements, not MPS performance or an infinite-horizon correctness guarantee. [Paper](https://arxiv.org/html/2607.19191v1).

**Release and license.** The Apache-2.0 [code snapshot](https://github.com/amap-cvlab/ABot-World/tree/fdc0d63d7da6ee8e304816733921ccb606dc75e9), committed September 4, supplies inference and a quantized streaming stack. The [causal 5B weight repository](https://huggingface.co/acvlab/ABot-World-0-5B-LF/tree/d26a3003701e70d38cd17e2af2faf63bd4ff7632) declares Apache-2.0 and lists a 10,540,744,232-byte merged transformer. The teacher remains unchecked on the release roadmap. A complete LongForcing trainer was not found in the inspected repository tree; a `long_forcing_dmd.yaml` filename does not prove training code is released. Third-party notices remain relevant.

**Data status corrects stale search results.** The repository announces an August 3 data release. The current official [Explorer dataset card](https://huggingface.co/datasets/acvlab/ABot-World-Explorer-500h) exposes 30,969 episodes with MP4s, native keyboard actions, captions and COLMAP annotations, declares Apache-2.0 and provides no semantic split. The card explicitly says “500h” is an identifier rather than an audited duration. Payload bytes, alignment and underlying game-asset rights were not audited here; do not substitute this for our original data without a separate source check.

**Implementable hypothesis for Worldline, not a result.** The immediate transferable experiment is to train the Room memory model using its own generated history for fixed suffixes and compare against teacher-observed training under equal realized compute and the same scene split. That is a generated-history ablation, not reproduction of LongForcing: our small supervised predictor lacks its long-horizon teacher and DMD setup. For the foundation path, first establish a faithful base and effective action conditioning; distillation cannot be assumed to invent reliable missing action semantics. A matched later ablation would vary teacher horizon only and retain full, unselected rollouts.

## Priority and exclusions

1. **Closest to the failed memory mechanism:** FloWM's spatially organized write/read/transport, with its action assumptions stated. It warrants an architecture comparison, not a claim that a larger GRU already implements it.
2. **Closest to the current Wan foundation:** Latent Spatial Memory uses the exact 5B family and a native latent cache, but its missing adaptation release and geometry requirements block a simple reproduction claim.
3. **Closest to insufficient action labels:** Olaf provides a measurable cross-scene action-effect objective, with substantial pretraining and an incomplete training release.
4. **Lowest-training-cost memory concept:** WorldKV, conditional on having a compatible causal cache and valid retrieval signals.
5. **Closest to teacher-observed/generated-history mismatch:** LongForcing, while retaining the distinction between its DMD teacher method and a simple supervised self-rollout loss.

Additional discovery leads were excluded when their evidence or relevance was weaker. CLAP has a relevant cross-embodiment curriculum, but robot end-effector transfer is less direct for this bounded audit. Long-Context State-Space Video World Models is useful background, but FloWM supplies the more direct dynamic-memory test and compares that architecture. RDR's full-rollout reconstruction objective is simple and relevant, but its central quantitative evidence is one chaotic PDE; it does not supply stronger visually grounded evidence than the selected items. JoyAI-Echo, DreamX and TetherMem were discovery leads, not fully audited additions.

The nine discovery queries were: (1) `site.arxiv.org world model persistent visual memory 2026 retrieval memory`; (2) `site.arxiv.org pretrained video world model sparse action labels 2026`; (3) `site.arxiv.org world model self generated history training 2026`; (4) `site.arxiv.org "video" "generated history" "2026" training`; (5) `site.arxiv.org "world model" "self-rollout" "2026"`; (6) `site.arxiv.org "Long-Context State-Space Video World Models"`; (7) `"ABot-World-0" github official weights license`; (8) `"LatentSpatialMemory" pretrained weights model checkpoint`; (9) `"Olaf-World" "license" "SkyReels"`.
